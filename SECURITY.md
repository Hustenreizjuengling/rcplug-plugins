# Security policy

Plugins run as root on the device, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(the repository's *Security* tab → *Report a vulnerability*). Include what an attacker
needs, what they can achieve, and how to reproduce it. You will get an answer within
two weeks.

## Supported versions

Only the latest release receives fixes.

## Scope

In scope: the plugins in this repository, for example ways to run commands on the
device through a plugin's web page or API, or to read files outside a plugin's data
directory. The platform (host, console) has its own repository, rcplug, with the same
policy.
